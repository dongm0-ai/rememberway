## 1. 한 문장

> 기기도 등록도 없이 사라진 치매 어르신을, **보호자의 기억만으로 찾게 돕고** 그 경험으로 **다음 실종을 막는** 보호자용 실종 대응 시뮬레이터.

발표 핵심 메시지: **"기기는 위치를 알지만 사람을 모른다. 기기가 비운 자리를 생성형 AI가 맡는다."**

## 2. 문제 정의

기기(배회감지기·스마트태그)와 등록 제도(지문 사전등록, 포항 ZIP)가 있어도 치매 어르신 실종은 늘어난다. 실종 직후 보호자는 당황해서, 또는 숨기려고, 경찰이 꼭 알아야 할 정보(오늘 목적지·경로·옷차림·약·보행)를 전달하지 못하고, 찾은 뒤에는 그 경험이 남지 않아 같은 일이 반복된다.

### 기기가 있어도 실종되는 이유 → 생성형 AI의 자리

| 기기·제도가 실패하는 지점 (한국 자료) | 왜 기술로 안 풀리나 | 생성형 AI가 하는 일 |
|---|---|---|
| 두고 나간다 (ZIP이 만들어진 이유, 부산 32명 10시간 수색) | 그날은 데이터가 0 | 보호자 머릿속 정보를 대화로 끌어내 구조화 |
| 보호자가 숨긴다 (신고 가족 10명 중 3명 치매 증상 미언급) | 기기는 사람의 말을 못 고침 | 돌려 묻는 질문 생성 ("드시는 약 있으세요?") |
| 목적지에 못 도착한다 (10명 중 8명 목적지 있음, 되돌아옴 20.7%) | 평소 동선은 출발지만 알려 줌 | 오늘 목적지와 경로를 물어 지도화 |
| 시민이 찾는다 (실종경보 발견의 23.2%가 시민 제보) | 기기는 시민 눈에 안 보임 | 실종경보 형식 인상착의 문장 생성 |
| 같은 사람이 또 사라진다 (치매 재실종 30,329건/2022~26.7) | 기기는 사건에서 배우지 않음 | 사건 요약 → 패턴 → 개인화 예방 계획 |

## 3. 3단계 구조

```
[평소 · 선택]            [실종 직후 · 핵심]                  [찾은 뒤 · 핵심]
대화형 등록              당일 대화                            실종 기록
추억 장소·습관·보행      오늘 목적지·경로·옷차림·소지품·약     어디서 어떻게 찾았나
   └─ 있으면 자동 채움 ──→ 되묻기로 빈칸 채움 ──→ 경찰 전달 요약 ──→ 패턴·예방 계획 → 등록 자동 갱신
```

| 단계 | 성격 | 생성형 AI가 생성하는 것 | 규칙·코드가 하는 것 |
|---|---|---|---|
| 평소 · 대화형 등록 | **선택** (없어도 다음 단계 작동) | 대화에서 추억 장소·습관·보행을 구조화 | 저장·삭제 (보호자 기기, 최소 항목) |
| 실종 직후 · 당일 대화 | **핵심** | 발화·사진 → 단서 JSON / 돌려 묻는 되묻기 / 실종경보용 인상착의 문장 | 즉시 신고 안내, 스키마 검사, 원문 대조(환각), 장소 실재 확인, 경로·교차로 지도화, R_max = 경과시간 × 보행속도 |
| 찾은 뒤 · 실종 기록 | **핵심** | 사건 요약 → 패턴 → 개인화 예방 계획 → 갱신된 등록 | 재발 위험 체크, 치매안심센터 연계 안내 |

핵심 규칙: **평소 등록에 있으면 당일 대화가 그 항목을 건너뛰고, 없으면 당일 대화가 그 자리에서 묻는다.** 등록 안 한 보호자도 같은 요약을 받고, 등록한 보호자는 더 빨리 받는다.

## 4. 단서 항목 (어디서 받아 어디에 쓰나)

| 단서 | 평소 등록(선택) | 당일 대화 | 찾은 뒤 기록 | 요약·지도에서 쓰이는 곳 |
|---|---|---|---|---|
| **추억 장소** (옛집·옛 직장·고향·자녀 집·자주 가던 곳) | "젊을 때 사시던 동네는요?" | 등록 없으면 "요즘 자꾸 가겠다고 하시는 곳 있나요?" | 실제 찾은 장소와 대조해 갱신 | 지도에 **후보 목적지**로 표시. 순위·확률 없음, 보호자 근거만 |
| **습관** (외출 시간대, 늘 걷던 길, 버스 타는 버릇, 말버릇) | 등록 | "오늘 어디 가신다고 했나요? 평소 어느 길로?" | "몇 시에 나가 어디서 헤맸나" → 패턴 | 오늘 **목적지와 경로**의 근거. 경로 위 교차로 표시 |
| **보행** (속도, 지팡이·보행기, 계단·언덕 회피, 절음) | "걸음은 어떠세요?" | "오늘 유난히 힘들어 보이셨나요?" | 발견 당시 상태 | ① 반경 계산의 보행속도 ② 인상착의 문장 ③ 물리적 장벽 큰 경로 후순위 |
| **오늘 목적지 + 경로** | — | 핵심 질문. 목적지를 답하면 **반드시 경로를 되묻는다** | 실제 발견 지점과 대조 | 지도의 경로선과 교차로 |
| **옷차림·소지품** | — | 발화 + 사진 → 인상착의 | — | 요약 상단, 실종경보 문구 |
| **복용약·치매 증상** | 등록 가능 (복용 여부만) | 돌려 묻기 ("요즘 길 헷갈려 하신 적 있나요?") | — | 경찰 전달 요약 (위험 요소) |
| **이전 실종 이력** | — | "전에도 이런 적 있나요?" | 자동 누적 | 위험 요소, 예방 계획 |

초안과의 차이: 추억 장소는 그대로 들어가되 **애착도 가중치·확률·순위를 뺀다.** 각 장소에 "보호자가 말한 근거"를 붙여 경찰이 판단한다.

추억 장소와 경로는 양자택일이 아니라 **한 쌍**이다. 추억 장소는 "어디로 갔을 가능성"(후보 목적지), 경로는 "그 중간 어디서 헤맸을 가능성"(교차로)을 담당한다. 한국 GPS 분석에서 목적지가 있어도 10명 중 8명이 도착하지 못했으므로 둘 다 있어야 한다. 경로·교차로 표시는 근거가 13건 분석 하나뿐이라 현장 자문으로 쓸모를 확인한다(11절).

## 5. 변수와 산출식 (규칙 기반, 코드)

- 입력: T_elapsed(경과 시간) · v_walk(보행 속도: 느림 0.5 / 보통 0.8 / 빠름 1.2 m/s) · L_last(마지막 목격 지점) · D_today(오늘 목적지) · P_mem(추억 장소 목록) · route(L_last→D_today 도보 경로, 지도 API) · X(route 위 교차로)
- R_max = T_elapsed × v_walk (이동 가능 최대 반경)
- 표시 대상 = { D_today, X ∩ 반경 R_max, p ∈ P_mem | dist(L_last, p) ≤ R_max } — 각 항목에 거리와 보호자 근거를 붙여 지도에 표시. 순위·확률 없음
- 고정 문구: "어르신은 목적지에 도착하지 못하고 **가는 길에서** 발견되는 경우가 많습니다."
- 생성형 AI는 계산에 관여하지 않고, 입력 변수(D_today, P_mem, 보행 특징)를 비정형 설명에서 뽑는 역할만 맡는다.

## 6. 생성형 AI 호출 4종

| 호출 | 입력 | 출력 | 고정 제약 |
|---|---|---|---|
| ① 구조화 | 발화 원문 + 사진 + 현재 시각 + (있으면) 등록 정보 | 단서 JSON (고정 스키마) | "입력에 없는 사실 금지, 모르면 null" |
| ② 되묻기 | 빈 항목 목록 | 질문 3개 | "치매세요?" 금지, 증상·약·길 헷갈림으로 돌려 묻기, 목적지 뒤엔 반드시 경로 |
| ③ 인상착의 | 사진 + 옷차림 JSON | 실종경보 형식 1~2문장 | 사진에 없는 특징 금지 |
| ④ 사후 기록 | 사건 서술 + ①의 JSON | 요약·패턴·예방 계획·갱신된 등록 JSON | 재실종 감소 효과를 단정하는 문장 금지 |

빼면: 고정 서식·직접 타이핑만 남고 되묻기·사진 설명·예방 계획은 사라진다.

## 8. 오류·윤리 대응 (요지)

- STT 오인식 → 화면에서 바로 수정, 글로 쓰기 항상 제공
- API 지연·장애 → 10초 내 응답 없으면 고정 서식 화면으로 자동 전환 (AI 없이도 최소 기능)
- JSON 형식 실패 → 스키마 검사 → 1회 재요청 → 서식 전환, 실패 횟수 기록
- 지도 API 미검색 → 삭제하지 않고 '위치 미확인'으로 유지
- 환각 → 'null 강제' + 출력 값의 원문 대조 ⚠ + 보호자 확인 전 미사용 + 발생률 측정
- 개인정보 → 이름 미수집(호칭), 동 단위 주소, 사진 동의·미저장, 등록은 최소 항목·보호자 기기 저장·삭제 가능, 약은 성분 아닌 복용 여부. 실험은 전부 가명 모의 사례
- 과신 → 순위·확률 미표시, 112 우선 안내, "가는 길에서 발견" 고정 문구
- 저작권 → 초안 스톡 사진 삭제, 직접 캡처·공공누리·CC만, 통계·연구 출처 표기

## 9. 기존 서비스와의 관계

| 기존 | 하는 일 | 우리와의 차이 |
|---|---|---|
| 포항 집(zip) (2026.8 시범) | 사전 등록 동선 → 경찰이 코드로 조회해 수색 우선지역 참고 | 우리는 등록 없이도 작동 + 당일 정보 + 사후 기록. ZIP 등록 방식(수동/GPS)은 미공개 → 포항북부서 확인 필요 |
| 밀양·영등포·안양 AI 수색 시스템 | CCTV 인물 추적, 위치 예측 (공공 예산) | 경쟁 아님. 우리 출력(인상착의·경로)이 그 입력 |
| 배회감지기·스마트태그 (행복GPS 38,721명 보급) | 착용 시 발견 660분 → 55분 | 기기 있는 사람용. 우리는 없는 날·없는 사람(이용률 2.8%) |
| 영국 Herbert Protocol / 귀가 면담 | 종이 양식 사전 작성 / 경찰이 72시간 내 방문 | 한국엔 없음. 화면 4가 보호자 주도로 대체 |

## 10. 근거 목록 (확인한 것)

- 2025년 치매 실종 신고 16,586건, 2026 1~7월 전년 대비 +14.4% — 경찰청
- 48시간 이상 장기실종의 71.7%가 치매 — 경찰청 국회 제출자료 (2026.9)
- 신고 가족 10명 중 3명 치매 증상 미언급, 휴대폰 소지 15~20%, 사전등록 30% 미만, 2~3시간에 4km — Yoo 외, *The Gerontologist* 2025 (한국 경찰관 16명 면담)
- 10명 중 8명 목적지 있으나 미도착, 배회는 교차로에서 시작, 도시 어르신 75.1% 배회 — 한국일보·한양대 GPS 동선 분석 (2023.9, 13건)
- 한 방향 직진 48.3%, 되돌아옴 20.7%, 행복GPS로 가족 직접 발견 2,682건 — 한국취약노인지원재단 (2017~2025)
- 실종경보 발견의 23.2%가 시민 제보, 치매환자 평균 발견 3시간 48분 — 경찰청 (파이낸셜뉴스 2026.8)
- 재실종 148,619건 중 치매 30,329건 (2022~2026.7) — 더팩트
- 배회감지기 착용 시 발견 660분 → 55분, 포항 이용률 2.8% — 건보공단 2022.1, 경북매일 2025.2
- 영국 보호자 12명: 52건 중 10건만 신고 (수치심·판단 두려움·경찰 불신) — Univ. of Portsmouth
- 치매 실종자 마지막 목격 지점에서 중앙값 0.8km, 발견자의 35%가 비수색자 — Koester & Stooksbury (미국, 참고값)

## 11. 남은 조건과 다음 할 일

1. **현장 자문** (대전 중구 지구대·치매안심센터 전화) — 자문 뒤 3쪽·8쪽에 한 줄 추가. 자문으로 확인할 세 가지(기록지 Q4):
   - 경찰은 보호자가 말한 목적지를 먼저 보는가, 가는 길을 먼저 보는가 (현장 관행)
   - 가는 길 중간에서 발견된 사례가 실제로 있는가 (한국일보 GPS 분석의 현장 검증)
   - 보호자가 지도에 평소 다니던 길을 표시해 주면 도움이 되는가, 별 차이 없는가 (화면 3 지도 기능의 생사 — "별 차이 없다"면 지도 비중을 낮춘다)
   - 추가(센터·경찰 공통): 한 번 실종됐던 어르신이 다시 신고될 때 지난번 정보를 쓸 수 있는가 (화면 4의 근거)
2. **ZIP 등록 방식 확인** — 포항북부서
3. **학생 명의 LLM API 키·한도 확인** — 전문강사
