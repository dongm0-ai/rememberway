# REMEMBER WAY AI — 테스트 케이스 (실험용)

그럴게요 팀 · 2026-11-03 · 앱: https://rememberway.vercel.app
모든 사례는 가짜 상황·가명입니다. 실제 사람·사건이 아닙니다.

두 가지로 나눠 시험합니다.
- **A. 생성형 AI 정리 시험 (자동)**: 보호자 말 → AI 정리 결과를 정답표와 비교. 숫자로 기록.
- **B. 화면 시험 (손으로)**: 실제로 휴대폰·PC로 눌러 보며 기대한 대로 되는지 확인.

## A. 생성형 AI 정리 시험 (13사례)

### 실행 방법
1. 휴대폰이나 PC에서 rememberway.vercel.app 을 연다
2. 주소창에 `https://rememberway.vercel.app/api/experiment?case=C4` 처럼 사례 번호를 넣어 연다 (한 번에 하나, 5~8초)
3. 나온 결과에서 아래 값을 표에 옮겨 적는다
   - `filled` 채운 칸 (정답표에 있는 칸 중 몇 개를 채웠나)
   - `hallucinated_keys` 환각 (비어 있어야 할 칸에 값을 적은 것) — **0개여야 함**
   - `unverified_flags` ⚠ (원문에서 확인 안 되는 값)
   - `followup_first_ok` 첫 되묻기가 정답인지
   - `forbidden_found` 이름·약 이름이 새어 나갔는지 — **비어 있어야 함**
   - `latency_ms` 걸린 시간
- 같은 사례도 실행할 때마다 결과가 조금 다를 수 있으니 **사례마다 3번씩** 돌려 평균을 적으면 더 좋은 실험입니다.
- 사례 원문·정답표: `data/mock_cases.json`

## B. 화면 시험 (손으로 눌러 보기)

준비: 휴대폰 크롬(또는 삼성 인터넷)으로 rememberway.vercel.app. 시험 전 "이 기기의 등록 정보 모두 지우기"로 처음 상태로.

| 번호 | 하는 것 | 기대 결과 | 통과 | 메모 |
|---|---|---|---|---|
| T1 | 처음 열기 | 112 안내 바로 아래 "어르신 집 주소를 설정해 주세요" 카드. 112·실종 버튼은 바로 누를 수 있음 | | |
| T2 | 집 주소 검색 "대종로 228" | 후보 목록에 도로명·지번이 보이고, 고르면 맨 위 칩이 "📍 대전광역시 중구 대종로 228"로 바뀜 | | |
| T3 | [📍 현재 위치로 설정] (위치 허용) | 지금 있는 곳의 도로명·지번이 뜨고 "이 동네로 설정" 가능 | | |
| T4 | 새로고침·브라우저 껐다 켜기 | 집 주소가 그대로 남아 있음 | | |
| T5 | 지금 실종됐어요 → "엄마가 안 와요." 만 쓰고 정리 | 화면 2에 거의 빈칸, 되묻기 "오늘 어디 가신다고 했나요?" 류 | | |
| T6 | T5에서 질문 건너뛰고 요약 | 화면 3 "돌아볼 곳"에 **집 근처 기본 장소**(경로당·공원·정류장·편의점)와 "보호자가 말한 곳이 없어 넣음" 안내. 어르신 정보에 "모름"은 안 보임 | | |
| T7 | T6에서 "가실 만한 곳 추가"에 "중앙시장" | 중앙시장이 1번으로 올라가고 동선·길찾기 버튼이 바뀜 | | |
| T8 | C7 문장으로 입력 | 지도의 [버스·지하철]이 미리 켜져 있고 점선 원이 보임. 할 일에 카드·택시 기록 한 줄 | | |
| T9 | 화면 3 "1번 ○○까지 길찾기" | 네이버 지도 도보 길찾기가 열림 | | |
| T10 | 돌아볼 곳에서 [가 봤어요] | 그 장소가 빠지고 남은 곳으로 순서가 다시 짜임 | | |
| T11 | [📍 내 위치 켜기] 후 후보 장소 근처(50m)로 걸어가기 | "○○ 근처에 왔어요. 확인하셨나요?" 알림 | | |
| T12 | 복사 → 메모장·카톡에 붙여넣기 | 번호 묶음 요약, "모름" 없음, 주소는 동까지만 | | |
| T13 | AI 없이 서식으로 입력 | 정해진 질문만으로도 화면 3 요약·지도가 나옴 | | |
| T14 | 처음 AI 쓸 때 동의 창에서 "AI 없이 서식으로" | 서식 모드로 넘어감 | | |
| T15 | C11 문장 입력 | 화면 2·3 어디에도 약 이름이 없음 | | |
| T16 | 인터넷 끊고(비행기 모드) 단서 정리 | 15초 안에 서식 모드로 전환 안내 | | |
| T17 | PC 넓은 화면 | 왼쪽 글·오른쪽 지도 두 칸, 폰과 같은 디자인 | | |
| T18 | 다크 모드 | 글자가 잘 보임 | | |
| T19 | 일지 저녁 알림 켜기 (홈 화면에 추가한 앱) | 18시·21시 알림 (안 쓴 날만) | | |

통과 못 한 항목은 메모에 화면 캡처와 함께 적고, 고친 뒤 다시 시험합니다.
