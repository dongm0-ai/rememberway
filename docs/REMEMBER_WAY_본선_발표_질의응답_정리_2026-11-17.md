## 1. 단체 인사 + 첫 문장 (15~20초, 외우기)

> (다 같이) **"안녕하십니까!"**
> "저희는 **그럴게요** 팀입니다. 저는 ○○를 맡은 ○○이고, ○○이는 ○○를 맡았습니다."
> ← **역할 채우기** (예: 문제 조사·화면 설계 / 하드웨어·시험). 인사할 때 역할을 말하면 "역할 분담" 질문에 미리 답한 거예요.

**첫 문장 (누가 + 어떤 불편 + AI로 어떻게):**
> **"저희는 치매 어르신 보호자가 겪는 '어르신이 사라졌는데 어디부터 찾아야 할지 모르는' 문제를 해결하기 위해, AI가 보호자의 말과 평소 GPS 기록을 정리해서 확인할 곳을 알려 주는 프로그램을 만들었습니다."**

## 2. 5분 발표 대본 (문·해·구·가, 4분 50초)

| 순서 | 시간 | 말할 내용 (우리 팀) | 담당 |
|---|---|---|---|
| 첫 문장 | 15초 | 위 첫 문장 | |
| **문 · 문제** | 50초 | "작년 치매 환자 실종 신고는 **16,586건**, 찾는 데 평균 **7.6시간**이 걸렸습니다(경찰청). 보호자는 당황해서 무엇을 말해야 할지 모르고, 어르신이 GPS 기기를 **끄거나 두고 나가시면** 위치도 알 수 없습니다. 이 문제는 **SDGs 3번(건강과 웰빙)**, **11번(모두에게 안전한 도시)**과 이어집니다." | |

| **구 · 구현·시연** | 1분 50초 | 아래 **3. 시연 순서** + "AI 답은 코드가 검사합니다. 시험해 보니 ○○○" (5. 숫자 참고) | |
| **가 · 활용 가치** | 50초 | "이 프로그램이 쓰이면 보호자가 당황한 첫 1시간에 **무엇을 말하고 어디부터 갈지** 바로 알 수 있습니다. 더 나아가 **경찰·치매안심센터**가 같은 정보로 함께 찾을 수 있습니다. **지금 만든 것**은 앱·목걸이·현관 수신기이고, **유심이 들어간 GPS**(휴대폰 없이 위치 전송)는 **다음 단계로 계획 중**입니다." | |
| 마무리 | 15초 | "다시 한번 말씀드리면, 저희 그럴게요 팀은 (첫 문장 반복). 감사합니다!" | |

**지킬 것**
- **결론 먼저** (두괄식). 긴 이야기가 결론보다 먼저 나오지 않게.
- **만든 것 vs 계획**을 딱 나눠 말하기 (6번 표).
- 발표는 **5분보다 조금 짧게** → 질문 시간이 길수록 유리해요.
- **문장 끝까지 또렷하게**: "작동하는 것 같은데요…" ❌ → "작동하는 것을 확인했습니다." ⭕
- 중요한 말 앞에서 **잠깐 멈추기** (0.5~1초).

## 3. 시연 순서 (1분 50초, 시연 영상 백업 필수!)

1. 첫 화면 → **📍 목걸이 위치 보기**: 지도에 목걸이 위치
2. **현관 수신기**: 문 센서 자석 떼기 → 목걸이 찬 사람이 지나감 → **텔레그램 알림** → 링크 누르면 앱이 열리고 외출 시각이 채워져 있음
3. **실종 정리**: 보호자처럼 말하기 → **AI가 경찰용 정보로 정리 + 빠진 것 되묻기** → 목걸이 마지막 위치 **[단서에 넣기]**
4. **확인할 곳 지도**: 추억의 장소·자주 머문 곳을 순서대로
5. **🔔 목걸이 찾기**: 휴대폰 버튼 → 목걸이에서 삐삐
6. (시간 남으면) **🛰️ GPS로 자주 머문 곳** → AI가 보호자에게 묻는 질문

> **사용자 상황으로 보여 주기**(교수님 강조): "지금 저는 어머니가 안 보여 당황한 보호자입니다"처럼 **역할극**으로 시연하면 좋아요.
> 시연이 안 되면 **현장에서 고치지 말고 바로 백업 영상** 틀기.

## 4. AI를 어떻게 썼는지 (가장 중요! "AI로 만들었어요"는 땡)

### 입력 → 처리 → 결과 (외우기)
| | 실종 정리 (AI ①②) | GPS 되묻기 (AI ⑦) |
|---|---|---|
| **입력** | 보호자가 말한 것 ("아까 2시쯤 시장 간다고 나가셨는데…") | 코드가 GPS에서 찾은 자주 머문 곳 ("석교동 어딘가, 13일, 오전 9시쯤") |
| **처리** | 생성형 AI가 말을 읽고 **경찰이 쓰는 칸**(마지막 본 시각·장소·옷차림 등)으로 나누고, 빈칸을 **되묻는 질문**을 만듦 | 생성형 AI가 **보호자에게 물을 질문**을 만듦 |
| **결과** | 경찰에 전할 요약 + 확인할 곳 지도 | "그곳이 어디인지, 좋아하시는 곳인지" 질문 → 보호자 확인 → 추억의 장소 |

### 어떤 모델을, 왜?
- **Upstage Solar (solar-pro4)**: 우리나라 회사가 만든 **한국어에 강한 생성형 언어 모델**. 안 되면 자동으로 **Google Gemini**로 넘어가요.
- **고른 이유 (비교 실험, 10/28~29)**: 같은 보호자 말 3가지를 넣어 봤더니 **Gemini는 보호자가 안 한 말을 1번 지어냈고**(환각), **Solar는 0번**이었어요. 대신 Solar가 2.5초쯤 느려요. → **틀리지 않는 게 더 중요해서 Solar**를 골랐어요.

### AI가 안 하는 일 (코드가 함)
- 확인할 곳 **순서·점수**, GPS에서 **머문 곳 계산**, 30일 지난 기록 **자동 삭제**, AI 답 **검사**.
- 이유: **"AI는 말을 잘 다루지만 틀릴 수 있어서, 판단은 정답이 있는 규칙(코드)에 맡겼습니다."**

### 쉬운 말로 바꾸기 (지식의 저주 조심!)
| 우리끼리 쓰는 말 | 심사위원께 하는 말 |
|---|---|
| 생성형 AI로 구조화 | 보호자 말을 **경찰이 쓰는 칸으로 나눠 정리**하는 AI |
| 프롬프트 | AI에게 주는 **지시문** ("없으면 비워 둬, 지어내지 마") |
| 환각 | AI가 **안 한 말을 지어내는 것** |
| 스테이 포인트 | 어르신이 **머문 곳** |
| DBSCAN | 가까이 모인 점들을 **한 장소로 묶는 방법** |
| API | 다른 프로그램에 **부탁해서 결과를 받아오는 창구** (식당 직원처럼) |
| BLE | **가까운 거리 블루투스** (이어폰처럼) |

## 5. 숫자로 보여 주기 (좋은 숫자만, 50% 미만은 말하지 않기)

### 지금 말할 수 있는 숫자 (진짜 시험 결과)
| 시험 | 결과 | 말하는 법 |
|---|---|---|
| AI 정리 (모의 보호자 말 3개, 실제 AI) | 지어낸 말 **0개**, 되묻기 규칙 **3/3** 지킴, 채운 칸 **15/18 (83%)** | "보호자 말에 없는 내용을 지어낸 경우는 0번이었습니다" |
| GPS 머문 곳 (가짜 30일 기록) | 건물 안에 머문 곳 **13일 중 13일 (100%)** 찾음 | "건물 안에 머문 곳은 모두 찾았습니다" |
| 서버 시험 (실제 사이트) | 위치 저장·잘못된 값 거부·삭제 **4/4** 성공 | |

### ⚠️ 말하지 않을 숫자
- 시장(가끔 간 곳) 찾기 0~67% → **말하지 않기**. 대신 "밖에서 서성인 곳은 일부 놓쳐서 **보호자 되묻기로 보완**합니다."
- **Bayat 2020의 F1 87%는 그 논문의 결과**예요. **우리 결과처럼 말하면 안 돼요.** ("저희가 따른 방법은 노인 대상 연구에서 87% 정확도를 보였습니다"는 OK)

### 본선 전에 꼭 재 올 숫자 (팀원끼리 시험)
- [ ] **현관 감지**: 목걸이 찬 사람이 문을 지나가기 **10번** → 알림 온 횟수 ___/10
- [ ] **목걸이 찾기 소리**: 휴대폰 버튼 **10번** → 울린 횟수 ___/10
- [ ] **블루투스 거리**: 신호가 잡히는 거리 ___m (시연 장소 비슷한 곳에서)
- [ ] **GPS 위치**: 목걸이 위치와 휴대폰 지도 위치 차이 ___m (밖에서 5곳)
- [ ] **사용해 본 사람 만족도**: 친구·가족 ___명, 5점 만점 ___점 (보호자 역할로 써 보게 하기)
- [ ] 숫자를 말하기 전에 **"이게 좋은 숫자야?"** 팀원끼리 확인

## 6. 만든 것 vs 계획 (섞어 말하면 질문 한 번에 무너져요)

| ✅ 지금 작동함 | 🔜 다음 단계 (계획) |
|---|---|
| 보호자 말 → AI 정리·되묻기 → 경찰용 요약 | **유심 GPS** (휴대폰 없이 위치 전송) |
| 확인할 곳 지도·순서 | 실제 어르신·보호자 대상 시험 |
| 일지·추억의 장소 등록 | 목걸이 배터리 절약 (GPS 전원 끄기) |
| GPS 자주 머문 곳 찾기 + AI 되묻기 | 점수(가중치)를 실험으로 조정 |
| 목걸이 실시간 위치 (어르신 휴대폰 앱 거쳐) | |
| 현관 수신기 알림, 목걸이 소리로 찾기 | |

## 7. 예상 질문과 답 (질문 시간 7분이 점수를 가름)

**기본 답변 틀 (어떤 질문이든 이걸로 시작):**
> "저희는 **치매 어르신 실종**이라는 문제를 해결하려고 만들었습니다. **○○로 시험**했더니 **○○**였습니다."

**꼬리질문은 좋은 신호예요** — 관심 있어서 계속 묻는 거예요. 모르면 **옆 친구가 이어서** 답해요.

| 질문 (★ = 교수님이 중요하다고 한 것) | 진짜 궁금한 것 | 우리 답 | 답할 사람 |
|---|---|---|---|
| ★ AI는 어디에, 어떻게 쓰였나요? | 얼마나 알고 썼나 | 4번 "입력→처리→결과" 표 그대로 + 모델 이름 | |
| 어떤 모델이고 왜 그거예요? | 비교해 봤나 | Solar vs Gemini 비교 (지어낸 말 0 vs 1) | |
| ★ 비슷한 작품이 많은데 뭐가 달라요? | 차별성 | "같은 실종 문제지만, 저희는 **기기가 꺼졌을 때**를 위해 **추억의 장소 + GPS로 자주 머문 곳**을 정리하고, AI가 **보호자에게 되물어** 확인합니다." | |
| 그냥 GPS 추적기랑 뭐가 달라요? | 차별성 | "추적기는 **켜져 있고 몸에 있을 때만** 쓸모 있습니다. 저희는 꺼졌을 때도 어디부터 찾을지 알려 줍니다." | |
| 팀이 직접 만든 부분은요? | 학생이 한 범위 | 각자 맡은 부분 (인사 때 말한 역할) | |
| ★ 아직 안 되는 기능은요? | 정직함 | 6번 표 오른쪽. "작동하는 부분은 ○○이고, ○○는 다음 단계로 고도화하겠습니다." | |
| 실제 사용자에게 시험했나요? | 검증 | "어르신 위치는 민감해서 **가짜 기록과 팀원 데이터**로 시험했습니다. 결과는 ○○입니다." (5번 숫자) | |

| 위치를 모아도 돼요? (법) | 안전 | "위치정보법 **제15조**에 따라 **본인 동의**가 필요해서, 시제품은 **팀원 본인 데이터로만** 시험했습니다." | |
| 휴대폰을 안 들고 나가시면? | 한계 | "실시간 위치는 안 옵니다. 그래서 **평소 기록으로 정리한 자주 머문 곳과 추억의 장소**가 필요합니다. 다음 단계는 유심 GPS입니다." | |
| 왜 목걸이예요? | 근거 | "연구에서 GPS 기기를 **목줄·열쇠고리로 가장 많이 썼습니다**(Doyle 2024, 91%). 건강보험 **배회감지기**도 몸에 차는 방식입니다." | |
| 자주 간 곳이면 좋아하는 곳이에요? | 깊이 | "아닙니다. 병원처럼 자주 가도 좋아하지 않는 곳이 있고, 고향처럼 요즘 안 가는 추억의 장소도 있습니다(Koester 2006). 그래서 **AI가 보호자에게 물어봅니다**." | |
| 머문 곳은 어떻게 찾아요? (꼬리질문) | 원리 | "① 그날 가장 느린 속도 무리를 '멈춤'으로 보고 ② 멈춘 사람은 GPS 방향이 제멋대로 흔들려서 그걸로 머문 곳을 찾고 ③ 건물에 들어가 GPS가 오래 끊기면 건물 안에 머문 겁니다 (박진관·오수열 2016 논문 식)." | |
| 30일·10초·3분은 왜요? | 근거 | "전부 **논문 값**입니다: 30일·3분은 노인 GPS 연구(Bayat 2020), 10초는 치매 어르신 GPS 연구(Shoval 2008)." | |
| 현관 수신기는 어떻게 알아요? | 원리 | "문이 열려 있는 동안 **문 앞에서 목걸이 신호**가 잡히면 알림을 보냅니다. 건강보험 **매트형 배회감지기**와 같은 원리입니다." | |
| 블루투스는 몇 m까지? | 시험 | "장소마다 달라서, **시연 장소에서 직접 잰 ___m**입니다." | |
| 시연이 안 되면? | 대비 | (말하지 말고) **바로 백업 영상** | |

## 8. 숫자와 근거 (질문 나오면 보고 답하기)

| 숫자 | 뜻 | 근거 |
|---|---|---|
| **30일** | GPS 기록을 보는 기간·서버 보관 기간 | Bayat 외 2020 (노인 GPS 4주) |
| **10초** | 목걸이가 움직일 때 위치 보내는 간격 | Shoval 외 2008 (치매 어르신 GPS) |
| **3분** | 3분 넘게 안 움직이면 쉼 | Bayat 외 2020 (3분 이상 = 정지) |
| **머문 곳 계산** | 느리고 방향이 제멋대로 = 밖에서 머묾, GPS 오래 끊김 = 건물 안 | 박진관·오수열 2016 (식 그대로) |
| **5%** | "유난히 크다" 기준 | 같은 논문 (유의수준 5%) |
| **4번 · 94m** | 같은 장소로 묶는 기준 | Bayat 외 2020 (노인 5명 값의 가운데) |
| 확인할 곳 점수 (추억 +3 등) | 순서 | **학생 초안 — 임의 설정, 실험으로 조정** |
| 근거 없는 것 | 목걸이 흔들림·문 앞 신호 세기 | 숫자를 정하지 않고 **현장에서 직접 잼(CAL)** |

## 9. 한계 (먼저 말하면 신뢰가 올라가요)

- 밖에서 서성인 곳은 **일부 놓침** → 보호자 되묻기·직접 등록으로 보완
- 어르신이 **휴대폰을 두고 나가시면** 실시간 위치 없음 → 다음 단계 유심 GPS
- **목걸이를 두고 나가시면** 못 찾음 (연구에서도 따로 재는 알려진 문제)
- 실제 어르신 대상 시험은 아직 (가짜 기록·팀원 데이터)
- 확인할 곳 점수는 **학생 초안**

## 10. 연습 체크리스트

- [ ] 심사위원이 오면 **다 같이 일어나 단체 인사** + 역할 소개
- [ ] 부스 안 **설 자리·말하는 순서** 정함
- [ ] **첫 문장 15초** 안에
- [ ] **문·해·구·가** 순서, 5분보다 조금 짧게 (타이머)
- [ ] **만든 것 vs 계획** 나눠 말하기
- [ ] 마지막에 **활용 가치 + 첫 문장 반복**
- [ ] AI 용어를 **초등학생도 알아듣게** (4번 표)
- [ ] **두 사람 모두** 모델 이름·작동 원리·고른 이유를 말할 수 있음
- [ ] 5번 **"본선 전에 재 올 숫자"** 채움, 50% 미만 숫자는 빼기
- [ ] AI가 틀릴 때 대비·개인정보를 말할 수 있음
- [ ] **오류 없는 시연 영상 백업** (짧고 핵심만)
- [ ] 친구가 심사위원 역할 → **꼬리질문 3단계** 모의 연습
- [ ] 같은 발표를 **두 번 연속** 똑같이
- [ ] 본선 당일 주문: **"내가 긴장한 거, 심사위원님들은 모른다."**
