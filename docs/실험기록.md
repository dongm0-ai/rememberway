**발견한 문제와 고친 것 (2차에서 확인)**
1. C11 — 프롬프트에 "성분명 금지"가 있는데도 AI가 약 이름을 적음 → **코드(verify.js)가 약 칸을 "복용 중 / 복용 안 함 / (오늘 약 안 드심)"으로만 바꿔 저장**하도록 함. AI를 믿지 않고 규칙으로 막음 (CLAUDE.md "AI 출력을 검증 없이 쓰지 않는다").
2. C7 — "코트"를 상의로 안 봄 → 프롬프트에 "점퍼·잠바·코트·조끼·가디건 같은 겉옷도 상의(top)" 추가.
3. C8 — "산책 다녀오신다고"를 목적지로 안 봐서 되묻기가 "오늘 어디 가실 예정이었어요?"로 같은 걸 또 물음 → 프롬프트에 "산책·운동·바람 쐬러처럼 목적만 말해도 today_destination에 그 말을 적는다" 추가.
4. C13 — 정답표가 틀렸음(AI 분류는 memory/recent/guardian 세 가지인데 정답표에 rising/frequent를 적음) → 정답표 수정. 자주 가는 곳 3곳을 모두 memory로 정리한 것은 규칙대로임.

**한계**: 사례 13개 모두 우리가 만든 가짜 문장이다. 실제 보호자 말투(더 길고, 더 헷갈리고, 음성 인식 오류 포함)로는 아직 시험하지 않았다. 같은 사례도 실행할 때마다 결과가 조금씩 다르다(C1의 ⚠가 1차 1개, 2차 0개).
